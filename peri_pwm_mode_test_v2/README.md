# peri_pwm_mode_test v2 — PWM/AXIモード切替と初期レジスタ設定

`peri_collect_unified` とは別の**PWM動作確認専用PSプログラム**です。`main.cpp` と `Makefile` のみでビルドでき、カメラ/OpenCVには依存しません。

## v2で追加した機能

以前正常に動いていた `peri_collect_unified` の初期設定値を、そのまま設定できる `setup` を追加しました。

| 項目 | AXI base + offset | 書き込む値 |
|---|---|---|
| target_raw0 | 0xA0020000 | 725 |
| target_raw1 | 0xA0020004 | 3453 |
| target_raw2 | 0xA0020008 | 2700 |
| target_raw3 | 0xA002000C | 267 |
| manual deadband | 0xA0040000 | 5 |
| auto deadband | 0xA0040004 | 20 |

書き込み後にレジスタを読み戻し、一致しなければエラーを表示します。これらの値は**以前のPSで用いていた値**であって、現在の配線・キャリブレーションが安全だと保証するものではありません。変更後の機体で同じ値を使えるか確認してください。

`setup` を実行するだけではワイヤの調整動作は行いません。モータの電源を切り、送信機のスティックを中立、意図しない前進が起こらない状態にしてから実行してください。レジスタ更新で目標角度が変わり得るため、**モータ通電状態で `setup` を実行しないでください。**

## コンパイル・実行

```bash
unzip peri_pwm_mode_test_v2.zip
cd peri_pwm_mode_test_v2
make
sudo ./peri_pwm_mode_test
```

デバイスに触れず試せるシミュレーション:

```bash
./peri_pwm_mode_test --dry-run
```

## コマンド

| コマンド | 動作 |
|---|---|
| `status` | REG0〜4に加えてdeadband / target_rawを表示 |
| `settings` | deadband / target_rawの現在値だけ表示（読み取り専用） |
| `setup` | **確認入力`SETUP`後**、上の6項目を書き込み、読み戻して確認 |
| `rom 100` | **確認入力`ROM`後**、ROM2/3=100を書き込む。数値は検証済み値に変更可 |
| `pwm` | 初期設定一致かつROM2/3非ゼロの場合のみ、bit16を1へ切り替え |
| `axi` | Rスティック中立・実機停止確認後にbit16を0へ戻す |
| `quit` | AXIモードのときのみ通常終了 |

ROM2/3の値は `setup` では変更しません。別途 `rom 100` などで設定してください。0/1chのストローク値にも手を加えません。

## 推奨する確認手順

1. **モータ電源OFF**、送信機接続確認、スティック中立、トグルを動作禁止側にする。新しいbitstreamがロード済みであることを確認する。
2. `sudo ./peri_pwm_mode_test` を起動し、`status` を確認する。
3. `setup` → **`SETUP`** と大文字で入力する。`setup = PASS` を確認する。
4. `rom 100` → **`ROM`** と大文字で入力する。`ROM2 = 100, ROM3 = 100` を確認する。
5. **まだモータ電源を入れない。** 先日の異常動作が収束したことを断定できないため、モータ非駆動状態で `Rstick_up`、`Lstick_up`、`toggle_low`、`mode_sync`、2/3chのエンコーダ値・目標角度をILA等で点検する。
6. 受信途絶時の停止、`wire_set`のタイムアウト・出力停止が未検証なので、それらが確認できるまではPWM走行テストに移行しない。

## 現在のソフト・PLの制約（重要）

- このPSプログラムは**モータを直接停止しません**。Ctrl+C/端末終了も停止指令にはならず、PWMモードのまま動作が続くことがあります。物理的なモータ電源遮断を確保してください。
- **`wire_set` はPL側の状態遷移**なので、このソフトで上限時間を設けることはできません。以前報告された「目標に向かって回り続ける」という症状が設定漏れだけで解消するとは限りません。
- 現在のPLにはPWM受信途絶時の確実な停止、およびPWM実行姿勢のPSへの読み出しがまだありません。安全対策なしの実機走行を推奨しません。
- PSが確認するのはAXIレジスタの読み戻しであり、ワイヤの物理位置・エンコーダの方向・フィードバック符号が正しいことを保証しません。
- 現行のコマンドIPは `0xA0010000`。REG4 bit16がPWM/AXI、bit14がstart、read bit15がdone。PWM切り替え操作ではstartパルスは発生させません。
- 同じAXIアドレスを別のPSプロセスから同時に操作しないでください。
