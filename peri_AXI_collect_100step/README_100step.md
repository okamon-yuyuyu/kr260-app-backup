# peri_AXI_collect_100step

元データ: peri_AXI_collect_safe_100posture(1).zip

## 変更内容
- manual / auto の姿勢入力は **0〜100を直接入力**。`52` はそのまま姿勢52を送信（10倍しない）。
- `g`: 現姿勢で前進。`b`: encoder base。`x`: 終了。
- 起動時と終了時の中立値は50。ROM0〜3=300、7bit二系統、START bit14、DONE bit15。
- CSV列 `stick3` は姿勢値0〜100そのまま。
- 画像ファイル名/CSVの `id`: 姿勢指令は1000〜1100（1000+姿勢値）、前進gは100、ゴールは900。従来の教師ラベルを利用する学習コードには変更が必要。
- 自動再生用コマンドtxtも姿勢値0〜100とgを1行ずつ記述。旧来の1〜9は今後姿勢1〜9を指し、旧キー操作との互換性はありません。

## ビルド
KR260で `make clean && make` を実行（OpenCV4、g++が必要）。本環境にはOpenCV4開発パッケージがなく、アプリ全体のビルドは未確認。旧バイナリ/オブジェクト/実験データは含めていません。

## 実機注意
- bitstreamのREG4: stick1[6:0], stick3[13:7], START[14], DONE(read)[15] を確認。
- 動作中タイムアウト時にも既存コードは中立復帰命令を出すため、動作確認時は必ず安全な試験環境を用意してください。
- PSが読めるDONEが正常であることをモータ駆動前に確認。
